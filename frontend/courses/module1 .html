Module 1 What's Cybersecurity

What is Cybersecurity?

By definition, cybersecurity is the practice of protecting computers, networks, programs, and data from unwanted access, damage, or theft.

This covers everything from a personal laptop to enterprise infrastructure — the same core problem, just at different scales.

Core Principles — The CIA Triad

Confidentiality

Keeps sensitive data secret and ensures only approved people can read it.

Integrity

Keeps data accurate and unaltered — no one changes it without permission.

Availability

Makes sure systems and data are ready and working for approved users when needed.

They pull against each other. Locking data down hard (confidentiality) can slow legitimate access (availability). Making a system highly available can widen the attack surface (confidentiality risk). Good security is a balance between the three, not maximizing each one independently.

Whoever works in cybersecurity is responsible for guaranteeing these three principles, together — not in isolation.

These aren't abstract risks — a breach can shut down hospitals, leak millions of people's personal data, or bankrupt a small company overnight. This is why guaranteeing confidentiality, integrity, and availability isn't optional — it's the job.

Four Key Words

To actually start in cybersecurity, there are four key words you'll need to know.

Vulnerability A weakness in a system that an attacker can exploit.
Threat Anyone or anything with the potential to cause harm, or that looks for a weak spot.
Mitigation A countermeasure — an action taken to reduce the likelihood or severity of a threat exploiting a vulnerability.
Risk The probability that a threat exploits a vulnerability, weighted by how severe the impact would be if it succeeds. Risk ≈ Likelihood × Impact
